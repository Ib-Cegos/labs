# Guide express de l’animateur

## À (dé)montrer aux apprenants :

- **Se repérer** : le panneau **Navigation**, à gauche, donne accès au sommaire et aux ateliers ou exercices. Les flèches permettent de passer d’un exercice à l’autre. L’onglet **Illustration**, s’il existe, affiche l’image utile à l’exercice.
- **Suivre les étapes** : cliquer sur la case d’une tâche la marque comme faite ; les tâches précédentes le sont aussi. La barre verte indique l’avancement (dans le sommaire également).
- **Adapter et noter** : **⚙ Paramètres** permet de renseigner les variables personnelles et d’adapter l’affichage (la puce rouge sur le bouton paramètres indique que des variables personnelles sont à leur valeur par défaut). **📝 Notes** permet de prendre des notes dans chaque exercice (elles sont visuellement rappelées dans le sommaire par une petite barre jaune).
- **Fluidifier la saisie** : le bouton de copie placé près d’un extrait copie le texte dans le presse-papier (pour le coller dans une VM ou une commande par exemple).
- **Imprimer** : Dans la fenêtre **⚙ Paramètres**, le bouton **Préparer l'impression** permet d'afficher tous les exercices du stage ensemble dans le navigateur, permettant l'impression et/ou l'export en PDF du cahier d'ateliers complet.

## À retenir

La progression, les notes, les variables et les préférences sont enregistrées **dans le navigateur**, pas transmises au formateur ni synchronisées entre appareils. Conseillez aux apprenants d’utiliser **⚙ Paramètres → Exporter mes données** régulièrement. Pour reprendre sur un autre navigateur ou appareil, ils devront importer ce fichier ; l’import remplace les données locales du stage.
