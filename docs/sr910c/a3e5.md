# Mise en place de l’hyperconvergence

## Etape 1 - Installation de Ceph

1. **Connectez- vous** à l’interface d’administration de votre **clusteur 3 noeuds**  
    Firefox -> Scénario 3 -> PVE-03 (Il est important pour la cohérence de l’atelier de choisir l’interface de PVE-03)
2. Sélectionnez **PVE-03**, **Ceph**, puis cliquez sur **Install Ceph**
3. Choisissez la version **squid**, avec le repository **No-Subscription**, puis cliquez sur **Start squid installation**
4. Dans la fenêtre **Setup**, Tapez **Y** Puis **Entrée**
5. Une fois l’installation terminée, cliquez sur **Next**
6. Dans l’onglet **Configuration**, renseignez :

    - Le Public Network : **172.20.10.x/24**
    - Le Cluster Network : **172.20.20.x/24**

    Puis, cliquez sur **Next**
	
7. Dans l’onglet **Success**, regardez les tâches qu’il vous reste à accomplir, puis cliquez sur **Finish**
8. Installer Ceph sur les 2 autres nœuds
    - pve-04 -> Ceph -> Install Ceph (suivez la procédure d’installation à l’identique)
    - pve-05 -> Ceph -> Install Ceph (suivez la procédure d’installation à l’identique)

## Etape 2 - Ajout des Ceph Monitors

> Idéalement, dans un cluster Ceph, il faut 3 monitors. Dans notre cluster, ça veut dire 1 par nœud.

1. Datacenter -> Ceph  
    La zone **Services** indique que seul PVE-03 (le premier Ceph installé) dispose d’un monitor. 
2. Pve-03 -> Ceph -> Monitor
3. Dans la zone **Monitor**, cliquez sur **Create**, choisissez **pve-04**
4. Répétez l’opération pour ajouter un monitor sur **pve-05**

> [!TIP] Comme vous pouvez le constater, ces opérations ont été exécutées depuis PVE-03, mais nous aurions pu les réaliser depuis n’importe lequel des 2 autres serveurs. La configuration globale de Ceph est répliquée sur tous les serveurs du cluster

## Etape 3 - Ajout d'un Ceph Manager

> Ce n’est pas une obligation, mais pour améliorer la disponibilité de la gestion de cluster, il est préférable d’avoir un deuxième Manager qui prendra le relais en cas de perte du premier. Contrairement aux Monitors, les Managers fonctionnent en Actif/Passif

1. Pve-03 -> Ceph -> Monitor
2. Dans la zone **Manager**, cliquez sur **Create**, choisissez **pve-04**
2. Datacenter -> Ceph  

> Vous pouvez constater dans la zone **Services** que les 3 Monitors et les 2 Managers apparaissent.  
Le statut du cluster Ceph reste néanmoins en Warning : Il nous manque encore les OSDs  

## Etape 4 - Ajout des OSDs
1. PVE-03 -> Ceph -> OSD
2. Cliquez sur le bouton **Create OSD**
3. Dans la fenêtre **Create Ceph OSD**, le seul disque disponible est déjà sélectionné (/dev/sdb). Pour ce test, l’OSD servira aussi de stockage pour la base de données de Ceph. Cliquez sur le bouton **Create**
4. Cliquez sur le bouton **reload** pour voit apparaître l’OSD de PVE-03 et ses caractéristiques
5. **Répétez** l’opération sur les 2 autres nœuds.

> Même si les l’OSD de tous les nœuds sont visibles depuis chaque nœud, la création des OSD ne peut se faire que sur chaque nœud individuellement.

> Datacenter -> Ceph  
  Le cluster Ceph apparaît maintenant sans aucun Warning

## Etape 5 - Création d'un pool

1. PVE-03 -> Ceph -> Pools
2. Cliquez sur le bouton **Create** et renseignez les champs :
    - Name : VMs
    - Size : 3 (= 3 répliques par VM)
    - PG Autoscaler Mode : On
    - Add as Storage : Oui

> Le nouveau stockage Ceph nommé **VMs** apparait maintenant sur chaque serveur Proxmox ainsi qu’au niveau du Datacenter

Il ne reste plus qu’à déplacer les disques virtuels des VMs sur ce nouveau stockage  
**Faites le nécessaire**

> [!WARNING] Vous rencontrerez peut-être une erreur lors du déplacement du disque EFI de votre VM Windows. Ce **bug** est lié à plusieurs facteurs :  
    - Le disque EFI est en RAW avec une taille très précise (128K)  
    - Le stockage Ceph (RBD) arrondit la taille à un multiple de 4 Mo  
    - Conséquence : Le "mirror" échoue car la taille ne correspond pas au secteur près.  
  Plusieurs solutions :  
    - Déplacer le disque VM arrêtée  
    - Supprimer et recréer le disque EFI  
    - Dans les 2 cas, il faut arrêter la VM. C’est un élément important à prendre en considération quand on migre vers du stockage Ceph
