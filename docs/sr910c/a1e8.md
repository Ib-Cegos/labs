# Sauvegarde des machines virtuelles (Mode natif)

### Étape 1 - Ajout d’un stockage NFS comme destination des sauvegardes

1. Ouvrez la console d’administration de votre serveur Proxmox
2. Dans l’arborescence, sélectionnez **Datacenter**, puis **Storage**
3. Cliquez sur le bouton **Add**, et choisissez **NFS** dans le menu contextuel
4. Dans la fenêtre **Add NFS**, renseignez les champs suivants :

    - ID : ```nfsBackup``` (Par exemple)
    - Server : ```172.20.10.15```
    - Export : **/mnt/ZFSPool/nfsBackup**
    - Content : **Backup** uniquement  
      Cliquez sur **Add**

d.	Vous devriez voir maintenant apparaitre dans la liste des Stockages de votre Datacenter **nfsBackup** de type **NFS**

### Étape 2 - Planification de la sauvegarde des VMs

1. Dans le menu **Datacenter**, juste en dessous de **Storage**, sélectionnez **Backup**
2. Cliquez sur le bouton **Add** pour ajouter un nouveau job de sauvegarde
3. Dans la fenêtre **Create Backup Job**, Onglet **General** renseignez les champs suivants :

    - Storage : **nfsBackup**
    - Schedule : **Every Day 21 :00**
    - Selection Mode : **All**
    - Compression : **ZSTD (fast and good)**
    - Mode : **Snapshot**
    - Enable : **Oui**

4. Jetez un coup d’œil aux options disponibles dans les autres onglets de la fenêtre **Create Backup Job**, puis cliquez sur **Create**
5. Votre nouveau Job de sauvegarde apparait maintenant dans la liste  
    Sélectionnez-le , et cliquez sur **Run Now** (Confirmez en cliquant ensuite sur **Yes**)
6. Vous pouvez suivre l’avancement de la sauvegarde en double-cliquant sur la tâche **Backup Job** apparaissant en bas de l’écran. La sauvegarde dure environ 5 minutes. **Attendez la fin de la sauvegarde**. Il est important pour la suite des ateliers qu’elle s’exécute correctement
